# tagesschau-news-dashboard

[DE] | [EN](README_EN.md)

Dieses Projekt ist ein News-Dashboard, das die Tagesschau-API nutzt, und dient als reines Lernprojekt für JavaScript.

## Technologien

Für dieses Projekt nutze ich folgende Technologien: HTML, CSS, JS und die Tagesschau-API (`https://www.tagesschau.de/api2u/news/`).

## Features

Man kann aktuelle Nachrichten anzeigen lassen, gefiltert nach Bundesland oder Ressort (z.B. Inland, Ausland, Wirtschaft, Sport). Jeder Artikel wird mit Titel, kurzer Beschreibung und einem Link zur Original-Quelle auf tagesschau.de angezeigt.

## Setup / Lokal starten

1. Repo klonen
2. Einen lokalen Server starten (in meinem Fall die VS-Code-Extension "Live Server")

## Rechtlicher Hinweis

Dieses Projekt ist ein nicht-kommerzielles Lernprojekt. Die Tagesschau-API wird ausschließlich für den privaten, nicht-kommerziellen Gebrauch genutzt, wie es die Nutzungsbedingungen der API vorsehen – Inhalte aus diesem Projekt werden nicht veröffentlicht oder über den persönlichen/schulischen Gebrauch hinaus verbreitet, und die Anfragen bleiben deutlich unter dem Limit von 60 Abrufen pro Stunde. Dieses Projekt steht in keiner Verbindung zur ARD oder Tagesschau.
